# AI Doesn’t Think Like You

*Let’s get it right this time.*

I detest that YouTube ad saying something like:

“Stop using ChatGPT like a newbie, people over 40…”
But the truth is, we do need to upgrade the way we use AI if we want better results.

New to Automato? Join us:

I’ve been talking with many entrepreneurs lately, and we all share the same issue. Maybe you do too. We get frustrated when AI doesn’t deliver what we envision, even when our request seems straightforward.
The root of the problem is our misunderstanding of what an LLM really is.
And the consequence? When we expect better results, the tools simply don’t perform as we imagine.
Sounds familiar?

We read the articles, we watch the videos, and we start believing that Agents can do magical things. We buy into the examples we see online, but something essential is missing.
I think the problem lies in how we humans think. Stay with me, it’s not what you might expect.

We ask our favorite LLM to perform a task as we imagine it should be done.
Look at this example:

Me: “Please extract my list of articles, URLs, and titles from this link. Organize the results in a spreadsheet with two columns: Title and URL.”
ChatGPT tries… and fails.
So I try again.
I figured out that my list of articles is also available as an RSS feed, so I changed the link in the prompt.
Still no luck.
Then I copy the content of the RSS XML file and paste it directly into ChatGPT. Ten seconds later, I get the full list perfectly formatted and ready as a CSV.
Eureka.
